Avant de commencer

Cette page se suit à votre rythme, les mains sur le terminal. Chaque commande a un bouton Exécuter : un clic l’écrit et la lance dans le terminal, à côté du texte. Au-dessus du terminal, le repère Où vous êtes dessine l’arborescence et le répertoire où vous êtes ; avec la VM, il est lu dans la VM après chaque commande.

Pratique Pour commencer

  • Dans la colonne de droite, cliquez sur Démarrer la VM : une VM Linux démarre dans le navigateur, sous le compte ada, en une vingtaine de secondes. Sur un petit écran, le terminal s’ouvre en bas (bouton Terminal).
  • Cliquez ensuite les commandes dans l’ordre de la page. Vous pouvez aussi taper les vôtres : le repère suit.

Question Ce que vous savez déjà

Dans ls -a notes, qu’est-ce qui est la commande, l’option, l’argument ?
Réponse
ls est la commande, -a une option (elle commence par un tiret), notes un argument. Une hésitation ? C’est le module 0, « Le terminal, le shell, la commande » : voyez la diapo Lire une ligne de commande et l’étape 1 du TP Premiers pas.

Préparer le terrain

Toute la page explore la même arborescence d’exemple, celle du TP. Ces deux commandes la créent : la première télécharge un script, la seconde le lance. Vous n’avez pas besoin d’en savoir plus pour la suite.

$ wget https://jmchantrein.github.io/Cours/shell/tp/premiers-pas/preparer.sh
$ bash preparer.sh
Dossier de travail prêt : /home/ada/atelier
Pour y entrer : cd /home/ada/atelier

Dans le repère, sous ada/, apparaissent preparer.sh après le premier clic, puis atelier/ après le second, avec ce qu’il contient.

Précaution Avec le compagnon (votre propre shell), le script refuse d’écraser un atelier qui existe déjà : c’est le cas si vous avez fait le TP. Votre compte remplace alors ada, et le repère décrit la VM, pas votre machine.

Des répertoires dans des répertoires

Les fichiers sont rangés dans des répertoires (des dossiers), qui contiennent eux-mêmes des fichiers et d’autres répertoires : une arborescence. Tout part d’un répertoire unique, la racine, qui s’écrit /. La commande ls (list) affiche ce que contient le répertoire qu’on lui donne en argument :

$ ls /
bin  dev  etc  home  init  lib  media  mnt  opt  proc  root  run  sbin  srv  sys  tmp  usr  var

Dans le repère, la racine / est en tête : ses noms sont ceux que ls affiche. Deux nous servent : home, qui contient un répertoire par compte, et tmp, pour les fichiers temporaires.

Le répertoire courant : pwd

Le shell travaille toujours dans un répertoire : le répertoire courant. C’est là qu’agit une commande à qui l’on ne dit pas où agir. pwd (print working directory) l’affiche :

$ pwd
/home/ada

Dans le repère, les pastilles lisent ce chemin depuis la racine : / puis 1 home, 2 ada, séparés par /. Le répertoire courant porte « vous êtes ici ».

À l’ouverture d’un terminal, le shell part du répertoire personnel du compte : /home/ada pour ada. Le repère le marque ~, son abréviation, que l’on retrouvera plus bas.

Ce que contient un répertoire : ls, ls -a

Sans argument, ls liste le répertoire courant ; avec un répertoire en argument, il liste celui-là, sans y aller :

$ ls
atelier  preparer.sh
$ ls atelier
journaux  notes  pionnieres.csv  projets  vieux

Question Prédisez, puis cliquez

Le repère montre dans atelier/ un nom en italique gris que ls atelier n’affiche pas. Que montrera ls -a atelier de plus que ls atelier ?
$ ls -a atelier
.  ..  .reglages  journaux  notes  pionnieres.csv  projets  vieux
L’option -a (all) montre aussi les noms cachés, ceux qui commencent par un point : .reglages, que le repère écrit en gris. . et .. sont dans tout répertoire : . désigne le répertoire lui-même, .. son parent, un cran plus haut. Ils serviront dans les chemins.

Changer de répertoire courant : cd

cd (change directory) change le répertoire courant. Il n’affiche rien quand il réussit : c’est pwd, ou le repère, qui le montre.

$ cd atelier
$ pwd
/home/ada/atelier
$ cd notes
$ pwd
/home/ada/atelier/notes
$ ls
a-faire.txt  idees.txt  lisezmoi.txt

Dans le repère, « vous êtes ici » descend d’un cran à chaque cd, et l’ancien répertoire garde l’étiquette « avant ». Dans le terminal, l’invite le rappelle aussi : ada@cours:~/atelier/notes$.

$ cd lisezmoi.txt
bash: cd: lisezmoi.txt: Not a directory

cd n’entre que dans un répertoire : sur un fichier, il refuse, et le répertoire courant ne change pas.

Un chemin relatif part du répertoire courant

Un chemin enchaîne des noms séparés par /. Sans / en tête, il est relatif : il se lit depuis le répertoire courant. atelier, puis notes, étaient déjà des chemins relatifs, d’un seul nom.

Question Prédisez, puis cliquez

Vous êtes dans notes. Où mène cd ../projets/site ? Suivez-le dans le repère avant de cliquer : .. remonte d’un cran.
$ cd ../projets/site
$ pwd
/home/ada/atelier/projets/site
1 .. remonte de notes dans atelier, 2 on descend dans projets, 3 puis dans site : le repère numérote chaque pas, depuis le départ, le répertoire courant.

Un chemin absolu part de la racine

Un chemin qui commence par / est absolu : il part de la racine, et désigne le même endroit quel que soit le répertoire courant. pwd en affiche un.

$ cd /home/ada/atelier/notes
$ cd /home/ada/atelier/projets/site
$ pwd
/home/ada/atelier/projets/site

Dans le repère, le départ est la racine /, puis une pastille par nom : même arrivée que tout à l’heure, par un autre chemin.

À retenir Relatif ou absolu

  • Relatif (../projets/site) : depuis le répertoire courant ; court, mais il dépend de l’endroit où l’on est.
  • Absolu (/home/ada/atelier/projets/site) : depuis la racine ; il mène au même endroit d’où qu’on parte.

. et .. : ici, et un cran plus haut

ls -a les montrait dans tout répertoire : . est le répertoire lui-même, .. son parent. Dans un chemin, .. remonte d’un cran ; . ne bouge pas.

$ ls -a
.  ..  index.html
$ ls ..
scripts  site

ls .. liste le parent de site, projets, sans changer de répertoire : « vous êtes ici » reste sur site.

Question Prédisez, puis cliquez

Toujours dans site : que liste ls ../../journaux ?
$ ls ../../journaux
serveur-2025-novembre.log  serveur-2026-novembre.log
1 .. remonte dans projets, 2 .. dans atelier, 3 on descend dans journaux, dont ls affiche les deux journaux.
$ cd ../..
$ pwd
/home/ada/atelier

Question Prédisez, puis cliquez

Vous êtes dans atelier. Que désigne notes/../projets/./site ? Que va afficher ls ?
$ ls notes/../projets/./site
index.html
1 on entre dans notes, 2 .. en ressort, 3 on entre dans projets, 4 . y reste, 5 puis site : c’est projets/site par un détour, et ls affiche son contenu, index.html.

~, cd seul, cd -

~ est l’abréviation du répertoire personnel : le shell la remplace par son chemin absolu avant de lancer la commande. echo le montre, puisqu’il affiche ses arguments :

$ echo ~
/home/ada
$ cd ~/atelier/notes

Dans le repère, ~ part du répertoire personnel, marqué ~ : ~/atelier/notes est un chemin absolu.

Deux retours rapides : cd - ramène au répertoire précédent (et l’affiche), cd sans argument au répertoire personnel.

$ cd /tmp
$ pwd
/tmp
$ cd -
/home/ada/atelier/notes
$ cd
$ pwd
/home/ada

Dans le repère, « vous êtes ici » saute de notes à /tmp, hors du répertoire personnel, revient dans notes, puis remonte à ~.

Pour la suite

À retenir À retenir

  • L’arborescence part de la racine / ; le shell est toujours dans un répertoire, le répertoire courant (pwd).
  • ls montre un répertoire sans y aller ; -a ajoute les noms cachés, et . et ...
  • cd chemin change de répertoire courant ; cd - revient au précédent, cd seul au répertoire personnel ~.
  • Un chemin absolu commence par / ; un chemin relatif se lit depuis le répertoire courant ; .. remonte, . reste.
